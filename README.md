# Bokō · Tejer el alma 🧶

Tienda en línea especializada en la comercialización de amigurumis y accesorios tejidos a crochet. La plataforma permite explorar un catálogo de productos, realizar compras, guardar artículos favoritos y solicitar pedidos personalizados. Cuenta con una interfaz moderna y adaptable, diseñada para ofrecer una experiencia de compra intuitiva y cercana a los clientes.

🔗 **Sitio web:** [boko-ruby.vercel.app](https://boko-ruby.vercel.app)  
*Próximamente disponible en bokocrochet.com.*

![Captura de Bokō](./docs/captura-home.png)

## Funcionalidades

- **Catálogo de productos:** navegación por categorías como videojuegos, accesorios, naturaleza, animales, anime y otras colecciones.
- **Filtros y búsqueda:** clasificación de productos por categoría, tamaño y precio, con opciones de ordenamiento por novedad y precio.
- **Carrito de compras:** gestión de productos seleccionados para realizar pedidos.
- **Lista de favoritos:** posibilidad de guardar productos de interés.
- **Perfil de usuario:** espacio personal para los usuarios de la plataforma.
- **Pedidos personalizados:** formulario para solicitar productos que no se encuentran en el catálogo o realizar pedidos al por mayor.
- **Reseñas de clientes:** espacio para compartir opiniones y experiencias sobre los productos.
- **Contacto:** canales de comunicación directa con la marca.
- **Información legal:** políticas de envío, términos y condiciones, y tratamiento de datos personales.
- **Diseño responsive:** adaptación de la interfaz a dispositivos móviles, tabletas y computadores.

## Tecnologías

Next.js (App Router) · TypeScript · Tailwind CSS · Supabase · Git · GitHub · Vercel.

## Cómo ejecutarlo en local

```bash
git clone https://github.com/alejaseg13-collab/boko.git

cd boko

npm install

npm run dev
```

Abre [http://localhost:3000](http://localhost:3000) en tu navegador para visualizar la aplicación.
